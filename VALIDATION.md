# Проверка Cofmart — 13 ноября 2026

## Дополнение от 14 ноября: удобства студента

Добавлены проверки повторения заказов, избранных вариантов и оценок. Повтор
использует текущие цену, доступность, расписание и квоту; подтверждение остаётся
отдельным действием. Проверены принадлежность заказов и избранного, объём/молоко,
сохранение комментария при повторе, удалённые позиции меню, повторные нажатия,
ограничения callback_data и разрешение оценки только владельцу после выдачи.
Изменение оценки обновляет один голос. Маршрутизация новых команд и callback
проверяется через настоящий Dispatcher с подменённой HTTP-сессией.

Персональные настройки текущего компьютера вынесены в игнорируемый локальный файл;
в публикуемом варианте роли не назначаются автоматически.

Ниже сохранён отчёт предыдущего прохода.

Проверен текущий Telegram-бот без базы данных и оплаты. Рабочий токен не использовался
для отправки сообщений: тесты подменяют HTTP-сессию Telegram.

## Что проверено

- 57 автоматических тестов прошли.
- Матрица из 125 комбинаций: исходный статус, целевой статус и роль/права сотрудника.
- Реальные обработчики aiogram: кофейня → напиток → объём → молоко → комментарий → подтверждение.
- Реальный Dispatcher с фиктивной HTTP-сессией: команды, переключение ролей,
  запрет самоназначения администратором, изоляция кофеен и работа только в личном чате.
- Два одновременных запроса «Взять в работу»: один успешный переход и одно уведомление.
- Отзыв прав, чужие заказы, чужие черновики, устаревшие ревизии и кнопки до перезапуска.
- Пауза и стоп-лист проверяются при создании и подтверждении; уже принятые заказы обслуживаются.
- Все девять окон приёма, точная граница закрытия, смена даты и эквивалентное время UTC.
- Тестовый режим ночью, переключение обратно на расписание и подтверждение после полуночи.
- Комментарии: лимит, пустой ввод, изменение, HTML-экранирование и сохранение цены.
- Ограничения callback_data и длины истории из пяти заказов с максимальными комментариями.
- `pip check`: конфликтов установленных зависимостей нет.
- Компиляция Python и `git diff --check`.

Команда повторного запуска:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Практические границы проверки

- Проверены код и обработка ответов Telegram через заглушки. Реальная доставка
  сообщений и вид интерфейса на телефоне требуют отдельной проверки в Telegram.
- Данные живут в памяти одного процесса. Перезапуск удаляет заказы, паузы,
  стоп-лист и назначения из команд. Несколько независимых экземпляров не делят данные.
- Уведомления отправляются по возможности; ошибки логируются. Постоянной очереди
  доставки и автоматических повторов ещё нет. Очередь/история остаются источником статуса.
- Оплата, возвраты, лимиты приготовления, остатки ингредиентов и интеграция с кассой
  пока не реализованы.
- Проверка настроек подтверждает формат ID; принадлежность ID человеку проверяется
  командой `/myid` из его аккаунта. Права в пользовательском settings.py в ходе аудита не изменялись.
